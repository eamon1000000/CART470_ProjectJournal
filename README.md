# Week 4

## Making a working example

This week I focused on making a full example score that sounds good musically across five phone groups. I prepared the audio in Ableton, using pads, birds, bells, recorded charango, and foley recordings. I then arranged them in our JSON score format so the piece moves through the room across the different phones. Each group has its own chain of lowpass, delay, reverb, and pan effects, and timed events fade sounds in, open up filters, and shift the panning over time. Writing a real piece in the format was a good test of what feels natural and what still feels awkward.


<img width="1470" height="1452" alt="Screenshot 2026-10-21 154722" src="https://github.com/user-attachments/assets/4b05a963-162f-4ad6-9559-a087b0638b42" />


I also defined the drift effect Gabriel asked for. Each group loops the same short clip with a small playback-rate offset, so the groups slowly fall out of phase with each other.

As a team, we mapped out the user flow for the app. Audience members scan a QR code, wait for loading, press Enter, and see their group number. Students use a form to build their score with dropdowns and effect icons, download the JSON, and send it to Gabriel to add to the repo. Re-uploading the file fills the form back in, which makes edits easy. The conductor page shows the queue and a playback timeline, and lets the conductor start each piece and remove phones.
