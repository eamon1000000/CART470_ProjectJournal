# CART-263-DLA

## Goal of this project
The goal of this project is to create an immersive listening experience distributed across participants mobile phones. In collaboration with professor Gabriel Vigliensoni, we will develop this system as a plug and play tool to be used by the students of his CART 346 Digital sound class. 

In essence, our system will enable his students to present rich, spatialized soundscapes, that can be set up in any room or configuration using a set of mobile phones as speakers.

On the phone, a user will load our web app, then place the phone on the floor or a table. Over the following minutes, the phones will play back a sound piece distributed across space, through he mobile phone speakers. The composers/designers determine the sound sources, their timing, position of the phones, and the grouping of phones.
